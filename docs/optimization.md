# Routing and acceptance

The planner assigns stops to a mixed fleet under capacity and time-window limits. Drivers and vehicles are paired deterministically with scarce licences preserved where possible. Each resource is used on at most one hub-to-hub route. This pairing is a heuristic and can miss better driver/vehicle combinations.

Eligible parcels require a clean ingestion record and either supported historical coordinates or an recorded manual confirmation. Verified shared physical identities with identical slots are combined. Matching only an area centroid never merges stops.

OR-Tools models weight, volume, cash, compatibility, slots and conservative peak-speed travel. Dropping a stop costs 1,000,000 objective units. Arc costs are distance-based cents and vehicle activation costs are included. Search uses parallel cheapest insertion then greedy descent with a five-second budget. The search may miss a better plan. Detailed time-dependent travel and breaks are rebuilt afterwards; any infeasible seeded stop is removed and reconsidered by insertion. Solver errors/timeouts with no incumbent use deterministic insertion. The forced-zero-budget switch is tested.

Insertion orders remaining stops by slot urgency and weight, tries every position in each compatible route and accepts only schedules respecting hard limits. Score is incremental AED cost plus 0.03 times resulting route duration in minutes. This score favors lower cost and shorter workloads, but does not guarantee the best plan. Accepted stops are never traded away for a cheaper plan. Parcels with unsupported locations stay held. The objective uses no per-stop failure probability. All accepted slots are hard, so generated missed-slot penalties are zero. A manual edit that breaks a slot is a hard finding and blocks approval.

Time integrates the 20/30 km/h peak boundary transitions; bikes multiply speed by 1.2. Each segment's rounded-up minute ETA is used for downstream travel. Distance is 1.4 times Haversine. Service uses villa four minutes, office/mall ten, apartment/default eight, COD two per COD consignment, one per extra consignment, and five per gated stop. A 30-minute break is inserted before the segment that would cross six hours. Work includes waiting, service, travel, break and return. Overtime beyond the roster end is allowed at AED 40/hour within the hard ten-hour maximum.

Summer bikes conservatively return before 12:30. Afternoon-only riding is not used, so feasible summer capacity may be understated. Heavy plus chilled is infeasible on the supplied fleet. Chilled always requires both a chilled-van type and a positive refrigeration flag, even though V01 has a contradictory refrigerated flag. Parcel dimensions are per piece; weight is total shipment weight. This conservative heavy rule may over-restrict multi-piece consignments.

The baseline groups by resolved area, sorts by slot and address, prefers the same vehicle for an area, and appends to the nearest feasible route with overflow. It uses exactly the same eligibility and scheduling hard checks, then the independent validator. The comparison measures this baseline against the proposed planner. It does not measure either against the real dispatcher.

The independent validator checks driver/vehicle existence and availability, licence, each imported parcel, duplicate assignments, individual restrictions, accumulated weight/volume/cash, shifts, max work, slot arrivals, geometry, service durations, break placement, return travel, ordering and full row accounting. It never trusts reported eligibility, parcel load or stop coordinates. Hard findings block approval. Overtime is soft and priced. It has no road-closure or live-speed data.
